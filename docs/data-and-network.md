# 数据与网络说明

## 1.2 起：雷达 Bench

2026-10-11 实测，旧的 `api.codexradar.com/api/v1/intelligence-efficiency`、`iq-history` 均返回 404。官网已迁移至 **雷达 Bench（150 分制）**。本 App 使用官网同一套公开、免登录的轻量摘要：

| 地址 | 用途 |
| --- | --- |
| `https://codexradar.com/data/radar-bench-binding.json` | 获取允许查询的模型与档位，以及基准版本、题池摘要 |
| `https://codexradar.com/api/radar-bench-score?model=…&effort=…&view=summary&selection=user-selected-v1` | 当前选定模型的某个档位：评分、题目覆盖、评测数、费用/耗时统计与每日历史 |

`selection=user-selected-v1` 是官网公开提供的显式选择参数，不是凭据。只使用固定 HTTPS 主机和路径，不执行上游内容或跳转到配置中提供的其他接口。校验模型/档位、基准版本、题池摘要、分值范围和历史归属；不接受串档位或不同基准的数据。

当前配置列出 6 个 GPT 模型、34 个档位，仅支持 Codex。Claude Code、DSH 卡片标为“暂未提供”，不请求未经确认的替代源。旧版已支持其他 harness，但上游迁移后不能继续提供它们的实时分数。

## 分数和费用

- 显示上游原始 `score`，不重新计算或缩放。列名为“雷达分”，与旧 IQ 不可直接比较。
- 每行注明覆盖题数，例如 `63/64 题 · 暂定`。无成绩显示“待测”，读取失败单独标注，不把缺失值当零分。
- 本 App 只对覆盖至少 **30 个不同题目**、有有效分数且本次读取未失败的档位强调最高分；并列时全部强调。30 题是本地展示规则，不是统计可靠性保证。不同档位的覆盖题目可能不同，比较仅供参考。
- 成本与耗时按上游统计的 `known_total / known_samples` 计算已知样本均值。耗时由毫秒换算为分钟；成本仅使用标为官方 API 等价的美元统计，并非订阅实扣。悬停可看已知样本数；数据未提供则显示 `—`。
- 一个档位失败不会丢掉其他成功档位。失败行保留同基准的上次成功快照，并明确标记；不参与本次最高分比较。

## 每日历史

新摘要提供 **UTC 自然日**的历史，而非旧 API 的小时序列。每个点是该判分日最后一个累计成绩；无判分日没有点，也不跨空缺日期连线。一个真实日点也会显示。

趋势仅使用对应模型、推理强度及同一评分版本的数据，展示最多近 7 天；横轴标日期和 UTC，悬停显示具体判分日、覆盖题数与分数。`1d / 7d` 是相对最新历史判分日的分差，不是相对当前时刻，也不是百分比；缺少对应日期就显示“样本不足”。不伪造小时数据。

## 请求生命周期与开销

```text
启动 → 只读本地缓存 → 打开面板
                         ↓
            获取模型目录 + 所选模型各档位
                         ↓
              展示结果并缓存，等待操作
                         ↓
          关闭面板 → 取消请求和尚未开始的队列
```

- 无启动请求、后台轮询、睡眠唤醒刷新或常驻计时器。
- 当前模型的分数和历史一起缓存 **60 秒**，目录在客户端内存中缓存 **1 小时**。
- 首次打开通常是 **1 次目录 + 5–6 次摘要**请求；切换到未缓存/已过期模型才读取该模型的档位，不扫描全部 34 个配置。
- 切换档位、悬浮趋势使用本地数据。切换模型会取消前一模型仍在进行的请求。关闭面板后不继续下载、不接受迟到结果。
- 最多 **2 个并发请求**；无自动重试；手动刷新有 3 秒防连点保护。面板保持打开也不定时刷新。
- ephemeral URLSession，不设置认证/Cookie；请求超时 12 秒、资源超时 18 秒。流式读取限制单个响应为 4 MiB。
- 2026-10-11 的 Astra MAX 摘要约 2 KB，包含每日历史；不下载完整逐题运行记录。大小会随上游历史增长。

## 缓存升级与隐私

缓存仍位于 `~/Library/Caches/com.local.gptiq/snapshot.json`，bundle identifier 仍为 `com.local.gptiq`，保留选择偏好。

1.2 使用缓存版本 3。旧 IQ 缓存不加载；第一次打开面板才取新基准数据。基准/题池版本变化时清理内存中的旧分数和趋势，绝不拼接不同基准。每个模型分别记录刷新时间；同基准的磁盘缓存支持离线恢复。

无遥测、无账号和聊天内容采集、无开机自启注册。点击 Codex Radar 链接由浏览器打开官网。
